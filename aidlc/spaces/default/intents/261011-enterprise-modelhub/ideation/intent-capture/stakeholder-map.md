# Stakeholder Map

## Stakeholders

| Stakeholder | Interest | Source |
|---|---|---|
| You, as owner of the CLI and the web app | Owns the work; decides scope and priority | [Q11] [Q12] |
| The Artifactory administrators | Need only a repository and a service account for the CLI to use | [Q11] [Q20] |
| The security and compliance team | Reviewers who approve what is brought in | [Q11] [Q2] |
| The teams that will fetch and use the models | Machine-learning engineers and data scientists who fetch models to work with | [Q11] [Q2] |
| The platform or infrastructure team | Runs Artifactory and the containers | [Q2] |
| Automated systems (training or serving pipelines) | Pull models through an interface | [Q2] |

| Stakeholder | Authority | Source |
